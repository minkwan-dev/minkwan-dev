## **👤 About Me**

React, TypeScript 기반의 개발자 원민관입니다. 새로운 기술과 다양한 문제 영역을 꾸준히 탐구하며 성장하고 있습니다. 단순히 화면을 개발하는 것을 넘어, 사용자와 만나는 첫 번째 경험을 설계하는 일에 집중합니다.

* **사용자 경험 설계**: 모달 플로우, 휴대전화 인증, 이미지 업로드 프리뷰 등 사용자 경험을 세밀하게 다듬습니다.
* **시스템 이해**: NestJS 기반 백엔드 구현 경험을 바탕으로, 클라이언트 요청이 서버에서 어떻게 처리되는지 이해하며 효율적인 협업을 추구합니다.
* **클라우드/인프라**: AWS(S3, CloudFront, EC2 등)를 활용한 애플리케이션 배포 경험이 있으며, CI/CD 파이프라인 구축의 중요성을 이해합니다.
* **체계적 기록**: 개발 과정에서 마주한 기술적 의사결정 과정과 문제 해결 과정을 체계적으로 문서화합니다.
